# Operations Playbooks

## What this section is

Procedures for **how the organization runs**: weekly rhythm, decision records, process improvement, internal handoffs, and knowledge capture.

## When to use it

Use when improving **recurring internal workflows** or **institutional memory**—not feature delivery (see [development](../development/README.md)).

## How to choose a playbook

| Situation | Start with |
|-----------|------------|
| End of week or sprint | [weekly-review.md](weekly-review.md) |
| Important fork in the road | [decision-log.md](decision-log.md) |
| Painful recurring workflow | [process-improvement.md](process-improvement.md) |
| Person or team change | [team-handoff.md](team-handoff.md) |
| Capture what only one person knows | [knowledge-capture.md](knowledge-capture.md) |
