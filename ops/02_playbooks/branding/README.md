# Branding Playbooks

## What this section is

Procedures for **brand strategy and expression**: core definition, visual direction, sector benchmarks, messaging architecture, tone of voice, and brand audits.

## When to use it

Use when the outcome is **durable brand decisions** or **consistency across touchpoints**. For campaign tactics, pair with [marketing](../marketing/README.md).
