# Getting Started

Welcome to **Innerflect Ops**: a Markdown-first operating system for prompts, playbooks, checklists, and standards.

## Who this is for

Engineering, marketing, brand, sales, project management, and operations—all share the same **taxonomy** and **templates** so work stays traceable and reusable.

## In your first 15 minutes

1. Read the root [README.md](../../README.md) for philosophy and structure.
2. Open [How to use this repo](how-to-use-this-repo.md) and pick one workflow that matches your role.
3. Open the playbook category that matches your task: [Playbooks hub](../playbooks/index.md).
4. Skim [AGENTS.md](../../AGENTS.md) if you use AI tools against this repository.
