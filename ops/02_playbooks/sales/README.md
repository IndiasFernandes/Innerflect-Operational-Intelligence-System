# Sales Playbooks

## What this section is

Procedures for **pipeline motion**: research, first contact, follow-up, call preparation, and post-proposal follow-through.

## When to use it

Use when the outcome is **starting or advancing a sales conversation**. For market-level positioning, use [marketing](../marketing/README.md).

## How to choose a playbook

| Situation | Start with |
|-----------|------------|
| Before any outreach | [outbound-research.md](outbound-research.md) |

| Planning multi-touch | [follow-up-sequence.md](follow-up-sequence.md) |
| Before a call | [call-prep.md](call-prep.md) |
