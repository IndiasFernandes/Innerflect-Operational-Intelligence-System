# Project Management Playbooks

## What this section is

Procedures for **client-facing delivery**: intake, commercial proposals, scope control, kickoff, handoff, and learning loops.

## When to use it

Use when coordinating **people, commitments, and artifacts** across a client or internal initiative. For code-specific setup, use [development](../development/README.md).

## How to choose a playbook

| Situation | Start with |
|-----------|------------|
| New client or workstream | [client-intake.md](client-intake.md) |
| Need a written proposal | [proposal-builder.md](proposal-builder.md) |
| Scope creep or ambiguity | [scope-definition.md](scope-definition.md) |
| Starting execution phase | [project-kickoff.md](project-kickoff.md) |
| Transitioning owners | [handoff.md](handoff.md) |
| After milestone or project end | [retrospective.md](retrospective.md) |
