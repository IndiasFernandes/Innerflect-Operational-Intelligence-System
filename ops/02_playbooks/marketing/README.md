# Marketing Playbooks

## What this section is

Procedures for **demand, messaging, and acquisition mechanics**: research, positioning, site and conversion analysis, content planning, and campaign design.

## When to use it

Use when the outcome is **market-facing narrative**, **funnel performance**, or **campaign structure**—not internal operating rhythm (see [operations](../operations/README.md)).

## How to choose a playbook

| Situation | Start with |
|-----------|------------|
| New category or market | [market-research.md](market-research.md) |
| Need competitor map | [competitor-analysis.md](competitor-analysis.md) |
| Define who you serve | [target-audience-definition.md](target-audience-definition.md) |
| Clarify offer vs alternatives | [offer-positioning.md](offer-positioning.md) |
| Site not converting | [website-analysis.md](website-analysis.md) + [conversion-analysis.md](conversion-analysis.md) |
| Plan editorial motion | [content-strategy.md](content-strategy.md) |
| Launch coordinated push | [campaign-planning.md](campaign-planning.md) |
